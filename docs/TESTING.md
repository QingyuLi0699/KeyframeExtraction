## 额外边界检查

- 配置拒绝重复 segment_id、反向起止时间、不一致的 duration_sec、含路径分隔符的编号。
- 非视频字节文件无法解码，开始实验保持禁用；缺失文件同样不能开始。
- 导出拒绝缺失/空 PNG、重复 frame_id、错误绝对时间、非法 task_id、零帧原因缺失。
- 对有效会话重复生成导出不改变原始选择数据。
- 1366×768 和 1920×1080 浏览器截图位于本目录；桌面工作区无横向溢出，较短视口通过页面滚动查看下方操作。
- Windows 写入 ZIP 导致 Vite 文件监听 EBUSY 的问题已修复：测试产物、文档和工具目录不参与开发监听。

## 范围与实际使用前的检查

自动化使用合成测试视频，未使用研究者正式传统节日素材。正式实验前需使用目标浏览器和实际视频核对编码兼容性、切分起点/PTS 偏移及存储容量。本次没有验证 Safari、Firefox、长时段超大规模图片存储或操作系统异常断电恢复。逐帧按钮为按指定帧率步长近似定位，界面及 README 已明确精度限制。

示例 ZIP 为测试参与者 P01 的合成素材结果，不应混入正式研究数据。测试上下文使用独立浏览器存储，不留测试参与者到研究者日常浏览器会话。
