# 独立练习素材

请将研究者确认的独立练习视频放在 `public/practice/practice.mp4`。
当前已提供独立练习视频 `practice.mp4`；更换时请使用研究者确认的独立素材，不能把正式实验素材自动当作练习视频。

`config.json` 的 `video_url` 相对于本配置文件解析，默认 `practice.mp4`；可修改为其他本站路径。
`title` 为练习片段标题，`start_time_sec` 为该练习文件在其原视频中的起点（秒）。时长自动从视频读取。
支持浏览器兼容的 H.264 MP4 / WebM。部署时该目录随网站发布。

也可在阅读说明后，于练习页面“选择练习视频”，临时关联独立本地文件，此时起点为 0。
此文件不会加入正式配置。练习数据只存在内存，刷新后丢弃。同一参与者已确认的 30 秒阅读和已提交的练习会单独记住，再次进入只需补做未完成步骤。
练习至少保存一张关联了任意任务且理由完整的关键帧才能提交；不设数量上限。
